أداة أوتوماتيكية سريعة لتثبيت وتفعيل **Spicetify CLI** و **Marketplace** لتطبيق Spotify على نظام Windows بنقرة زر واحدة، مع دعم التحديثات التلقائية واستعادة الإعدادات بعد تحديثات Spotify.

---

## ✨ المميزات (Features)

* 🛍️ **تثبيت Marketplace تلقائياً:** تنزيل وتفعيل متجر Spicetify مباشرة لتتمكن من اختيار الثيمات والإضافات بسهولة.
* 🔄 **التحديث التلقائي (Auto-Updater):** فحص وتحديث الأداة لأحدث إصدار تلقائياً من GitHub.
* ⚡ **إصلاح أخطاء التثبيت:** تجاوز مشاكل التعليق (Timeout) وإغلاق عمليات Spotify بالقوة أثناء التثبيت.
* 🛡️ **وضع الاستمرارية (Make Permanent):** إنشاء مهمة مجدولة لضمان بقاء Spicetify واختصاراته شغال حتى بعد تحديثات Spotify الرسمية.

---
