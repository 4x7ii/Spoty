# 🎵 Spoty — Spicetify & Marketplace Installer

![Version](https://img.shields.io/badge/Version-5.6-green)
![Platform](https://img.shields.io/badge/Platform-Windows-blue)
![Python](https://img.shields.io/badge/Python-3.x-yellow)

A fast, automated utility to install and configure Spicetify CLI and Marketplace on Windows for Spotify with a single click, featuring auto-updates and automatic config restoration after Spotify updates.

---

## ✨ Features

* **📥 Auto Marketplace Installation:** Downloads and enables the Spicetify Marketplace directly so you can choose themes and extensions effortlessly.
* **🔄 Auto-Updater:** Automatically checks for and updates to the latest release from GitHub.
* **⚡ Smart Error & Timeout Handling:** Bypasses freezing issues and force-kills stubborn Spotify processes during installation.
* **🛡️ Make Permanent Mode:** Creates automated scheduled tasks and startup scripts to ensure Spicetify and your shortcuts remain fully functional even after official Spotify updates.

---

## 🚀 Usage

### 1. Run the Executable (.exe)
* Download the latest release from the [Releases](https://github.com/4x7ii/Spoty/releases) page.
* Run `spoty.exe`.

python Spoty.py
